# Advent-of-Code

My solutions to the 2021 [Advent of Code](https://www.adventofcode.com) daily programming challenges, written in Python.

## The Problem

- Advent of Code is a series of daily programming puzzles released each December, each requiring a different algorithmic or logical approach.
- The 2021 challenges cover topics such as binary parsing, pathfinding, data simulation, and geometric computation.
- Working through them provides structured practice in algorithmic thinking and clean Python implementation.

## The Approach

Each day has its own Python solution in `src/`, working against a personalised input dataset in `data/raw/`. Challenge instructions are preserved in `Resources/`.

Solutions are liberally commented with the reasoning behind each approach. Code includes:

- `# LEARNING` annotations marking something new encountered while solving.
- `# TODO` markers in later challenges flagging areas where the approach could be improved.

## Value Delivered

- 2021 Advent of Code challenges solved with documented reasoning for each solution.
- Serves as a personal log of learning progress across algorithmic problem types.
- Useful reference for anyone working through the same challenges.

## Scope & Status

- **Project type:** Learning / personal practice
- **Current state:** Archived (2021 challenge set)
- **Known limitations:**
  - Solutions use personalised input data; others will need to substitute their own `data/raw/` files.
  - Not all 25 days may be complete.
  - Code style varies across days, reflecting learning progression.

## Tech Stack

- **Language:** Python
- **Format:** Python scripts

## Who This Is For

Developers interested in the author's algorithmic problem-solving approach, or anyone comparing solutions to the 2021 Advent of Code.
